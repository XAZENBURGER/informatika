# 📷 Photo Codec — прототип кодека сжатия фото (сайт)

Учебный прототип: сжатие фотографий **с минимальными потерями** + обратное
восстановление. Работает полностью в браузере, без сервера и зависимостей.

## Запуск

```bash
cd photo-codec
python3 -m http.server 8000
# открыть http://localhost:8000
```

(Можно и просто открыть `index.html` двойным кликом — всё локальное.)

## Как устроен пайплайн

```
ENCODE                                    DECODE
файл → растр → JPEG(q) → [gzip/LZ] → .pck → [gunzip] → JPEG → растр
        lossy слой      lossless слой       контейнер   декод
```

1. **Декод в растр** — браузер превращает PNG/JPEG/... в пиксели (`ImageBitmap`).
2. **JPEG-кодирование (этап с потерями)** — `canvas.toBlob('image/jpeg', quality)`.
   Внутри: цвет YCbChroma subsampling 4:2:0 → блоки 8×8 → DCT → квантование
   (вот здесь и «теряются» данные) → энтропийное кодирование (Huffman).
   quality 0.92–0.95 ≈ визуально без потерь (PSNR обычно ≥ 40 дБ).
3. **LZ-слой (без потерь)** — байты JPEG дожимаем `CompressionStream('gzip')`.
   Обычно даёт ещё ~1–5%, зато строго обратимо.
4. **Контейнер `.pck`** — свой мини-формат (magic `PCK1`, версия, флаги, размеры),
   чтобы decode знал: есть ли gzip внутри и сколько байт читать.

Decode делает ровно обратные шаги и сверяет magic/SOI-маркер JPEG — если файл
повреждён, вы получите понятную ошибку, а не битую картинку.

## Что показывает сайт

- сравнение оригинала и восстановленного изображения бок о бок;
- **PSNR / SSIM / MSE** — объективные метрики «насколько минимальны потери»;
- степень сжатия и время encode/decode;
- лог пайплайна по шагам (видно, что происходит с байтами);
- сохранение контейнера `.pck` на диск и повторное восстановление из него.

## Файлы

| файл | роль |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление |
| `codec.js` | сам кодек: JPEG-слой, LZ-слой, формат `.pck`, метрики |
| `app.js` | UI-логика: drag&drop, кнопки, таблица метрик |

## Идеи для развития

- заменить JPEG на WebP/AVIF (`toBlob('image/avif')`) — лучше качество при том же размере;
- настоящий lossless-режим: PNG-растр + gzip (roundtrip будет пиксель-в-пиксель, PSNR = ∞);
- добавить delta-кодирование каналов и RLE как ещё один учебный lossless-слой;
- Web Worker, чтобы большие фото не подвешивали UI.
