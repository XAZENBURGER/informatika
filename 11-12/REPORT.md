# Краткий теоретический конспект и результаты по всем пунктам работы.

## Пункты 2–3. Первая программа, запуск из командной строки
Файл: `src/lab.cpp`, исполняемый: `lab.exe`.

```bat
g++ -std=c++17 -o lab.exe src\lab.cpp
cd build            :: переход в каталог с lab.exe
lab<Tab>            :: автодополнение имени (l + Tab)
lab.exe             :: вывод текста в терминал
```

Вывод программы:
```
Hello from lab.exe! Line 1
This is lab.exe. Line 2
```

## Пункты 4–6. Перенаправление вывода: `>` и `>>`
```bat
lab.exe > o.txt     :: текст НЕ появляется в терминале — он записан в o.txt
type o.txt          :: проверка содержимого
```
* `>` — перенаправление stdout в файл; **старое содержимое файла стирается**
  без предупреждения. Если после изменения текста в программе снова выполнить
  `lab.exe > o.txt`, в файле окажется только новый текст.
* `>>` — **дописывает** вывод к существующему содержимому файла:
  ```bat
  lab.exe >> o.txt  :: теперь в o.txt вывод лежит дважды
  ```
* Повтор последней команды — клавиша ↑ (стрелка вверх) + Enter.

## Пункт 7. Что делает приведённый код
```cpp
if (char prev; cin.get(prev)) {
    cout.put(prev);
    for (char ch; cin.get(ch);)
        if (ch != prev)
            cout.put(prev = ch);
}
```
Код читает поток **посимвольно** и печатает символ, только если он отличается
от предыдущего напечатанного. То есть удаляет идущие подряд **повторяющиеся
символы** (это аналог `uniq` на уровне символов).
Пример проверки (реализация — `src/dedup_chars.cpp`):
```
ввод:  aaabbbcccdddeee   ->   вывод: abcde
ввод:  hello world       ->   вывод: helo world
```
Замечание: `prev = ch` — присваивание, возвращающее новое значение prev,
поэтому одна и та же переменная и обновляется, и печатается.

## Пункт 8. `cin >> name` против `getline(cin, name)`
Разница в поведении (см. `src/str_compare.cpp`):

| Ввод | Пример 3.1 (`cin >>`) | Пример 3.2 (`getline`) |
|------|----------------------|------------------------|
| `Ivan Petrov Sidorov` | `Greetings, Ivan` | `Greetings, Ivan Petrov Sidorov` |

* оператор `>>` пропускает пробелы-разделители и читает **одно слово** до
  первого пробела; остаток строки остаётся в потоке;
* `getline` читает **всю строку целиком до символа конца строка**, включая
  пробелы (сам символ '\n' в строку не попадает).

## Пункт 9. unique.exe — удаление идущих подряд повторов строк
Файл: `src/unique.cpp`. Проверка через перенаправление потоков:
```bat
g++ -std=c++17 -o unique.exe src\unique.cpp
unique.exe < input.txt > output.txt
type input.txt   :: apple / apple / banana / banana / cherry / apple
type output.txt  :: apple / banana / cherry / apple
```
Обратите внимание: последнее `apple` осталось — повтор удалён только если
строки идут **подряд**.

## Пункт 10. Пайп `|`: sort + unique
Символ `|` передаёт stdout левой команды в stdin правой.
Так как unique убирает только *соседние* повторы, сначала сортируем:
```bat
sort input.txt | unique.exe              :: результат в терминал
sort input.txt | unique.exe | more       :: просмотр «экранами»
sort input.txt | unique.exe > result.txt :: результат в файл
```
После сортировки одинаковые строки оказываются рядом, и пара `sort | unique`
удаляет **все** дубликаты (аналог `sort -u`).

## Пункт 11. Последовательность и условное выполнение: `&`, `&&`, `||`
* `команда-1 & команда-2` — просто последовательный запуск обеих.
* Код возврата: `return 0` из `main` = успех, ненулевой = неуспех.
  Проверить его можно командой `echo %errorlevel%` (cmd) или `echo $?` (bash).
* `команда-1 && команда-2` — команда-2 только **при успехе** команды-1.
* `команда-1 || команда-2` — команда-2 только **при неуспехе** команды-1.
* Конструкция целиком:
  ```bat
  команда && echo Success || echo Fail
  ```

## Пункт 12. dupcheck.exe — поиск дубликатов по коду возврата
Файл: `src/dupcheck.cpp`: возвращает 1, если две подряд идущие строки совпадают,
иначе 0. Готовая связка для пользователя:
```bat
sort input.txt | dupcheck.exe && echo File has NO duplicate lines || echo File HAS duplicate lines
```
Результаты проверки (см. `duplicates.txt`, `noduplicates.txt`):
```
sort duplicates.txt     | dupcheck.exe  -> код 1 -> "File HAS duplicate lines"
sort noduplicates.txt   | dupcheck.exe  -> код 0 -> "File has NO duplicate lines"
```

## Пункт 13. Аналог команды more
Файл: `src/mymore.cpp`, исполняемый `mymore.exe`.
Читает stdin или файл из аргумента, печатает по `LINES-1` (по умолчанию 23)
строк, затем останавливается и ждёт нажатия клавиши (Enter — далее, q — выход).
```bat
mymore.exe bigfile.txt
sort input.txt | mymore.exe
```
