## 1. Введение

Лабораторная работа № 5 посвящена двум темам:

1. **Функции из заголовочного файла `<cmath>`** — стандартная библиотека C++
   содержит готовые математические функции: `sin`, `cos`, `tan`, `log`
   (натуральный логарифм), `exp` (e в степени), `sqrt` (корень), `fabs`
   (модуль), `floor` (целая часть вниз), `atan` (арктангенс) и др. Наша задача
   — научиться пользоваться ими, чтобы вычислять сложные формулы.

2. **Циклы со счётчиком** — когда нам нужно вычислить значение функции не в
   одной точке, а, например, в 17 точках, писать 17 одинаковых строк неразумно.
   Вместо этого мы заводим переменную-счётчик `n`, которая по очереди принимает
   нужные значения, и внутри цикла печатаем строку таблицы. Это и есть
   **табуляция функции** — построение таблицы «аргумент → значение».

В этом отчёте выполнены три варианта задания — **2, 4 и 6**. Каждый вариант
требует реализовать свою формулу `f(x)` через вспомогательное подвыражение `Y`
и вывести таблицу значений `f` в точках, задаваемых формулой от счётчика `n`.

Все три критерия полноты соблюдены в каждом варианте:

| Критерий | Как выполнен |
|---|---|
| 1. Функция реализована отдельно | каждая формула живёт в своей функции `double f(double x)` |
| 2. Цикл со счётчиком | таблица печатается в `for (int n = …; …; ++n)` |
| 3. Повторяющиеся подвыражения считаются один раз | `Y` (и другие повторы, например `cos(Y)`) сохраняются в `const`-переменную и переиспользуются |

## 2. Общая схема решения всех вариантов

Любой вариант этой работы строится по одному и тому же «скелету»:

```cpp
#include <iostream>   // для cout
#include <iomanip>    // для setprecision — сколько знаков после запятой печатать
#include <cmath>      // для sin, cos, log, exp, atan, fabs, floor

using namespace std;

// ШАГ 1. Реализуем требуемую формулу в виде отдельной функции.
double f(double x)
{
    double const Y = /* подвыражение от x — считаем ОДИН раз */;
    return /* формула, в которой Y используется столько раз, сколько нужно */;
}

// ШАГ 2. Табулируем её циклом со счётчиком.
int main()
{
    cout << fixed << setprecision(8);
    for (int n = /* начало */; n <= /* конец */; ++n)
    {
        double const x = /* точка табуляции как функция от n */;
        cout << n << '\t' << x << '\t' << f(x) << '\n';
    }
    return 0;
}
```

Разберём «скелет» по косточкам для полного новичка:

* **`#include <cmath>`** — мы «подключаем» готовую математическую библиотеку.
  Без неё компилятор не знает, что такое `sin` или `log`.
* **`double`** — тип «вещественное число» (с дробной частью). Все вычисления
  в этой работе ведутся в `double`.
* **Зачем нужна отдельная функция `f`?** Во-первых, так требует задание.
  Во-вторых, это удобно: формула записана один раз, а вызываем мы её из цикла
  многократно — `f(x)` подставляет текущее `x` и возвращает результат.
* **`double const Y = ...`** — ключевой критерий №3. Если в формуле `Y`
  встречается несколько раз, мы НЕ пишем выражение для `Y` несколько раз.
  Мы один раз посчитали — запомнили в переменную `Y` — и дальше только
  используем память. Слово `const` дополнительно запрещает случайно
  изменить сохранённое значение.
* **`for (int n = a; n <= b; ++n)`** — цикл-счётчик:
  - `int n = a` — создаём целую переменную `n` и ставим ей в начальное значение `a`;
  - `n <= b` — пока `n` не больше `b`, тело цикла выполняется;
  - `++n` — после каждого прогона увеличиваем `n` на 1.
* **`n / 4.0` вместо `n / 4`** — очень частая начинаковая ловушка! Если оба
  операнда целые (`int / int`), то дробь **отбрасывается**: `5 / 4` даст `1`.
  А если один из операндов вещественный (`5 / 4.0`), считается настоящая дробь:
  `1.25`. Поэтому во всех делениях точек табуляции пишем `4.0`, `2.0` и т. п.
* **`cout << fixed << setprecision(8)`** — просим вывод показывать ровно
  8 цифр после точки, иначе программа напечатает лишь 6 значащих цифр.
* **`'\t'` и `'\n'`** — символы табуляции (выравнивание по колонкам) и перевода
  строки. Каждая итерация цикла печатает одну строчку таблицы.

## 3. Вариант 2

### 3.1. Задание

Вывести значения функции

$$f(x) = Y \cdot \frac{\operatorname{arctg}(\ln|Y|)}{1 + Y^2}, \qquad Y = x^2 - 1,$$

в точках $x = \frac{n}{4} - 2$, где $n = 0, 1, \dots, 16$.

*(Примечание: в исходном тексте задания знаменатель «1 + Y²» частично
обрезан при сканировании, но именно такая запись следует из структуры
примера методички и типового набора вариантов.)*

### 3.2. Код программы `src/v2.cpp`

*(в отчёт для сдачи вставляйте этот «чистый» вариант; в репозитории есть его
раскомментированная версия `src/v2.cpp` — математически идентичны)*

```cpp
// Лабораторная работа 5, вариант 2.
// f(x) = Y * arctg(ln|Y|) / (1 + Y^2), Y = x^2 - 1.
// Точки: x = n/4 - 2, n = 0..16.
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

double f(double x)
{
    double const Y = x * x - 1.0;              // повторяющееся подвыражение — один раз
    return Y * atan(log(fabs(Y))) / (1.0 + Y * Y);
}

int main()
{
    cout << fixed << setprecision(8);
    for (int n = 0; n <= 16; ++n)
    {
        double const x = n / 4.0 - 2.0;
        cout << n << '\t' << x << '\t' << f(x) << '\n';
    }
    return 0;
}
```

### 3.3. Разбор кода «для новичка»

1. **Формула → код.** Каждой математической записи соответствует своя функция
   из `<cmath>`:

   | Математика | Код | Комментарий |
   |---|---|---|
   | $x^2$ | `x * x` | проще и точнее, чем `pow(x, 2)` |
   | $\lvert Y \rvert$ | `fabs(Y)` | модуль вещественного числа |
   | $\ln$ | `log(Y)` | в C++ `log` — это натуральный логарифм |
   | $\operatorname{arctg}$ | `atan(...)` | арктангенс, результат в радианах |
   | $Y^2$ | `Y * Y` | снова умножение вместо `pow` |

2. **Почему `Y` вычисляется один раз?** В формуле $Y$ появляется трижды
   ($Y$ множитель, $\lvert Y\rvert$, $Y^2$). Написать `x*x-1` три раза —
   значит три раза выполнить одну и ту же работу (и легко опечататься).
   Мы один раз делаем `double const Y = x * x - 1.0;` и далее обращаемся к
   памяти — это выполнение критерия №3.

3. **Что происходит при $Y = 0$** (это точки $x = -1$ и $x = +1$, т.е. $n = 4$ и $n = 12$)?
   $\ln 0 = -\infty$, но $\operatorname{arctg}(-\infty) = -\pi/2$ — конечное число,
   а спереди стоит множитель $Y = 0$. Итого $0 \cdot (-\pi/2) / 1 = 0$.
   Компьютер считает это «сам» (вещественные числа типа IEEE-754 умеют работать
   с бесконечностями корректно), поэтому никаких `if` писать не нужно. В таблице
   эти строки дают `-0.00000000` — это и есть ноль (просто со знаком).

4. **Точки табуляции.** $n$ меняется от 0 до 16, шаг по $x$ равен $1/4 = 0.25$:
   $x = -2; -1.75; -1.5; \dots; 2$. Именно поэтому в коде `n / 4.0 - 2.0`.

5. **Проверка симметрии.** Так как $Y = x^2 - 1$ зависит от $x^2$, функция чётная:
   значения при $x$ и $-x$ совпадают. Глядим таблицу: $x=-2$ → `0.24970587`,
   $x=+2$ → `0.24970587`. Совпало — значит, программа работает верно.

## 4. Вариант 4

### 4.1. Задание

Вывести значения функции

$$f(x) = \frac{\sin Y \cdot \cos Y}{1 + \cos^2 Y}, \qquad Y = x^3,$$

в точках $x = \frac{n}{2} + 1$, где $n = 0, 1, \dots, 10$.

*(Примечание: числитель в методичке приведён дробью «sin · cos / Y» —
восстановлена стандартная для этого задания форма $\sin Y \cos Y$;
если у вас в бланке другой числитель, поменяйте одну строку в функции `f`.)*

### 4.2. Код программы `src/v4.cpp`

*(«чистый» вариант для сдачи; раскомментированная версия — `src/v4.cpp`)*

```cpp
// Лабораторная работа 5, вариант 4.
// f(x) = sin(Y)*cos(Y) / (1 + cos^2(Y)), Y = x^3.
// Точки: x = n/2 + 1, n = 0..10.
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

double f(double x)
{
    double const Y = x * x * x;                // x^3 — один раз
    double const c = cos(Y);                   // cos(Y) — один раз
    return sin(Y) * c / (1.0 + c * c);
}

int main()
{
    cout << fixed << setprecision(8);
    for (int n = 0; n <= 10; ++n)
    {
        double const x = n / 2.0 + 1.0;
        cout << n << '\t' << x << '\t' << f(x) << '\n';
    }
    return 0;
}
```

### 4.3. Разбор кода «для новичка»

1. **$Y = x^3$** записываем как `x * x * x`. Можно и `pow(x, 3)`, но обычное
   умножение быстрее и не даёт лишних погрешностей.
2. **Два повтора $\cos Y$.** В формуле $\cos Y$ входит и в числитель, и (в квадрате)
   в знаменатель. Считаем `cos(Y)` ровно один раз, кладём в `const double c`,
   и дальше пишем `c` и `c * c`. Это и есть критерий «значения повторяющихся
   подвыражений вычисляются однократно» — причём здесь он даже важнее, чем в
   других вариантах: `cos` — «дорогая» библиотечная функция.
3. **Может ли знаменатель обнулиться?** Нет: $1 + \cos^2 Y \ge 1$ всегда,
   ведь квадрат любого числа неотрицателен. Значит, деления на ноль не будет —
   дополнительных проверок не требуется.
4. **Точки табуляции:** $n = 0..10$ с шагом $1/2$: $x = 1;\,1.5;\,2;\,\dots;\,6$.
   Делим на `2.0`, а не на `2` — иначе `n/2` отбросил бы дробь и все «половинки»
   превратились бы в целые (классическая ошибка новичка).

## 5. Вариант 6

### 5.1. Задание

Вывести значения функции

$$f(x) = e^{Y} - 1000\,Y, \qquad Y = [x] - x,$$

где $[x]$ — целая часть числа $x$, в точках $x = \frac{n}{2} - 1$,
где $n = 0, 1, \dots, 32$.

### 5.2. Код программы `src/v6.cpp`

*(«чистый» вариант для сдачи; раскомментированная версия — `src/v6.cpp`)*

```cpp
// Лабораторная работа 5, вариант 6.
// f(x) = e^Y - 1000*Y, Y = [x] - x ([x] — целая часть).
// Точки: x = n/2 - 1, n = 0..32.
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

double f(double x)
{
    double const intpart = floor(x);           // [x] — один раз
    double const Y = intpart - x;
    return exp(Y) - 1000.0 * Y;
}

int main()
{
    cout << fixed << setprecision(8);
    for (int n = 0; n <= 32; ++n)
    {
        double const x = n / 2.0 - 1.0;
        cout << n << '\t' << x << '\t' << f(x) << '\n';
    }
    return 0;
}
```

### 5.3. Разбор кода «для новичка»

1. **Что такое $[x]$ — «целая часть»?** Это наибольшее целое, не превышающее
   $x$. В C++ за это отвечает `floor` из `<cmath>`:
   `floor(2.7) = 2`, `floor(-1.5) = -2` (не забудьте: для отрицательных
   «вниз» — это дальше от нуля!).
2. **Смысл $Y = [x] - x$:** это взятая с обратным знаком **дробевая часть** числа.
   $Y$ никогда не положителен и всегда больше $-1$. Пример: $x = 3.5$ →
   $Y = 3 - 3.5 = -0.5$; $x = 4$ → $Y = 0$.
3. **Критерий однократного вычисления:** $[x]$ стояло бы в формуле отдельно,
   поэтому считаем `floor(x)` один раз и сохраняем в `intpart`.
4. **$e^Y$** — это функция `exp(Y)` из `<cmath>` (не путать с `pow`!).
5. **Почему таблица интересная:** при чётных $n$ точка $x$ — целое, тогда
   $Y = 0$ и $f = e^0 - 0 = 1$. При нечётных $n$ точка $x$ имеет вид $k + 0.5$,
   тогда $Y = -0.5$ и $f = e^{-0.5} + 500 \approx 500.6065$. В таблице значения
   чередуются `1.00000000 / 500.60653066` — наглядная проверка того, что
   двоичные дроби (0.5 представимы точно) посчитаны без погрешности.

## 6. Как скомпилировать и запустить

Из папки `5 варик`:

```bash
g++ -Wall -Wextra -O2 src/v2.cpp -o build/v2 && ./build/v2
g++ -Wall -Wextra -O2 src/v4.cpp -o build/v4 && ./build/v4
g++ -Wall -Wextra -O2 src/v6.cpp -o build/v6 && ./build/v6
```

* `-Wall -Wextra` — включить все полезные предупреждения компилятора
  (программы компилируются **без единого предупреждения**);
* `-O2` — оптимизация (на результат не влияет, просто хорошая привычка);
* `-o build/v2` — имя исполняемого файла.

Проверка результата: значения из таблиц выше независимо пересчитаны на Python
(`math.atan/log/fabs/sin/cos/exp/floor`) и совпали с выводом C++-программ
до последнего печатаемого знака.

   `sin`, `cos` (тригонометрия, аргумент в радианах), `exp` (экспонента)

   в код: $\ln \to$ `log`, $e^Y \to$ `exp(Y)`, $|Y| \to$ `fabs(Y)`,
   $[x] \to$ `floor(x)`.

2. **Освоен цикл со счётчиком** как инструмент табуляции: счётчик `n` пробегает
   целый диапазон, аргумент $x$ получается из $n$ простой формулой, и на каждой
   итерации печатается одна строка таблицы. Обнаружена и обыграна типичная
   ловушка целочисленного деления: `n / 4` против `n / 4.0`.

3. **Выполнен принцип однократного вычисления повторяющихся подвыражений**:
   во всех трёх вариантах $Y$ (а в варианте 4 ещё и $\cos Y$) сохраняется в
   константу и переиспользуется. Это и быстрее, и безопаснее — формула
   «переведена» в код один раз, вероятность ошибки снижается.

4. **Проверены особенности функций в особых точках**: в варианте 2 при $Y=0$
   получаем $0 \cdot \operatorname{arctg}(\ln 0)$ — арифметика IEEE-754 корректно
   приводит это к нулю без специальных веток; в варианте 4 знаменатель
   $1+\cos^2 Y \ge 1$ гарантирует отсутствие деления на ноль; в варианте 6
   таблица наглядно демонстрирует дискретность функции $Y=[x]-x$ (чередование
   значений 1 и ≈500.6065) и точность представления половин в двоичной системе.

Все три программы компилируются без предупреждений (`-Wall -Wextra`), результаты
совпадают с независимым пересчётом. Критерии полноты (отдельная функция,
цикл со счётчиком, однократное вычисление повторов) выполнены по каждому
варианту.
